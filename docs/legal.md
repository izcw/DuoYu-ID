# 服务条款、隐私政策与成年人声明

公开阅读地址 /legal/terms 和 /legal/privacy，登录前可查看，链接以新页面打开，不替用户勾选，不丢失已填登录内容。正文分别位于 server/templates/terms.html 和 privacy.html，共用 legal.html 布局与 auth/legal.css。

本项目按个人运营、联系邮箱2405824084@qq.com、仅允许年满18周岁使用编写。运营主体公示为“多鱼账号个人项目运营者”，没有虚构公司名称。当前年龄限制为用户自我声明，不是实名或身份证核验。若实际运营者身份、部署地区、第三方处理者或数据处理实践发生变化，需据实补充并更新政策，而不能仅更新日期。

## 功能

登录页及手机扫码确认页默认不勾选“已阅读并同意《服务条款》和《隐私政策》”；界面不额外显示年龄文案，服务条款仍规定仅限年满18周岁用户。邮箱验证码发送、密码、验证码、通行密钥、身份验证器、扫码创建/直接验证和交互式授权继续前均需确认。已有账号的安全设置发送验证码属于已认证的安全操作，不额外要求重复登录勾选。

后端保护相关登录接口；缺少当前协议版本或成年声明返回400，不会继续验证密码或发送验证码。各类协议的标准OAuth/OIDC令牌端点及已建立会话的正常续期保持原协议行为。

GET /api/legal 返回当前version、minimum_age=18、age_verification=self_declaration及公开文档地址。项目自写登录表单须先向用户展示文档和默认未选的成年人/协议确认，再发送：

```
X-Duoyu-Legal-Version: GET /api/legal 返回的 version
X-Duoyu-Adult: true
```

这两个请求头表示用户本次明确作出的声明。项目不能在用户未阅读确认时自行默认填true。不得把本条款勾选作为所有第三方共享、跨境或敏感信息处理的概括授权，原项目授权流程仍保留。

022迁移新增user_legal_acceptances，按账号与版本记录首次/最近确认时间及成年声明，不额外为该记录采集IP或User-Agent。匿名失败请求不会创建账号确认记录，成功建会话时与会话写入同一事务；已认证的交互式继续确认记录归属于当前账号。版本号由server/legal.go统一提供给模板及API。

## 文案与实践

政策涵盖邮箱、密码哈希、昵称头像、会话Cookie及本地展示缓存、WebAuthn公钥及设备资料、加密TOTP共享密钥、恢复码摘要、扫码票据、项目角色/准入、开发者凭证及MCP、邮件提供方与加密待发正文、安全日志、版本确认、权利请求及未成年人处置。没有承诺未实现的自助注销、身份证核验、邮件必达或固定备份销毁期限。

密码/头像/邮箱等可由账号页管理；当前注销或导出申请通过公开联系邮箱核验后处理。用户注销中心不等于独立项目已保存业务数据自动删除。

法规核对依据：[个人信息保护法](https://www.cac.gov.cn/2021-08/20/c_1631050028355286.htm)、[民法典](https://www.cac.gov.cn/2020-06/01/c_15925617772683192.htm)。这些链接用于说明编写依据，不构成对项目全部运营实践已满足法定义务的保证。
